# Influencer Hunter

Полноценный исходный проект настольного приложения для Windows 10/11 x64. Стек: Tauri 2 + React + TypeScript + Rust + SQLite.

## Что уже реализовано

- Отдельное окно Windows-приложения, без необходимости открывать браузер для работы с базой.
- Локальная SQLite-база блогеров и рекламодателей. База создаётся автоматически при первом запуске.
- Создание, редактирование и удаление записей.
- Поля профиля: социальная сеть, ссылка, ник, ниша, подписчики, город, контакты, медианные просмотры, охват, активность, коммерческий потенциал, статус менеджера, объяснение оценки, дата и источник проверки, заметки.
- Фильтрация и быстрые статусы в собственной базе.
- Разбор части параметров из обычного русского запроса: социальная сеть, ниша, диапазон подписчиков, города, количество результатов.
- Раздельные поисковые запросы для каждой выбранной площадки. Если выбрана одна площадка, запрос строится только под неё; если несколько — открывается отдельный поисковый запрос на каждую.
- Экспорт блогеров в CSV и XLSX.
- Создание резервной копии SQLite через системный диалог сохранения.
- Открытие профиля, источника и копирование контактов.
- Нет облачной базы, платной подписки, API-ключей, серверов или фоновой передачи локальных записей.

## Важное ограничение поиска

Эта версия не выдаёт результаты веб-поиска за автоматически проверенные профили. Кнопка «Начать поиск» открывает Google-запросы `site:` во внешнем браузере для выбранных платформ. Пользователь проверяет найденный публичный профиль и заносит подтверждённые сведения в локальную базу.

Автоматическое получение подписчиков, последних публикаций, просмотров, комментариев и контактов из VK, YouTube, Telegram, TikTok и Instagram **пока не реализовано**. У платформ разные правила доступа; часть данных закрыта или ограничена, а официальные API могут требовать отдельные ключи, разрешения или иметь квоты. Поэтому приложение не генерирует фальшивые карточки и не придумывает статистику.

Оценка «без менеджера» хранится как проверяемый статус с текстовым обоснованием, а не как выдуманный процент. Отсутствие упоминания менеджера не считается доказательством его отсутствия.

## Где хранится база

В Windows Tauri создаёт каталог приложения в пользовательской папке данных. Ожидаемое расположение:

`%APPDATA%\ru.influencerhunter.desktop\influencer_hunter.sqlite`

Точный путь показывает кнопка с иконкой базы в верхней панели. Резервная копия создаётся в выбранное пользователем место. Удаление программы не должно затрагивать пользовательскую базу, но перед переустановкой всё равно рекомендуется сохранить резервную копию.

## Сборка установщика Windows

Для конечного пользователя в готовом `.exe` не нужны Node.js, Rust, Python или терминал. Однако **в этой среде готовый установщик не собран**: рабочий контейнер Linux, в нём не установлены Rust toolchain и Windows MSVC build tools. Поэтому файл `InfluencerHunter_Setup.exe` нельзя честно приложить как уже собранный.

Сборка выполняется на Windows 10/11 x64:

1. Установить Node.js LTS, Rust stable и Microsoft C++ Build Tools (компонент MSVC).
2. Установить WebView2 Runtime, если его ещё нет в Windows.
3. В каталоге проекта выполнить `npm install`.
4. Выполнить `npm run tauri:build`.
5. NSIS-установщик появится в `src-tauri/target/release/bundle/nsis/`. Скрипт `scripts/build-windows.ps1` переименует его в `InfluencerHunter_Setup.exe`.

Tauri собирает NSIS setup.exe и использует WebView2; в конфигурации включён режим автоматического скачивания установщика WebView2, если среда выполнения отсутствует. Документация: [Tauri Windows Installer](https://v2.tauri.app/distribute/windows-installer/).

## Сборка через GitHub Actions

В `.github/workflows/windows-build.yml` добавлен Windows CI workflow. После загрузки проекта в репозиторий GitHub его можно запустить вручную через вкладку **Actions → Build Windows installer → Run workflow**. Workflow установит инструменты на Windows runner, соберёт NSIS-инсталлятор, назовёт его `InfluencerHunter_Setup.exe` и прикрепит как downloadable artifact к запуску workflow.

Плата за работу самого приложения не требуется. GitHub Actions — только необязательный способ собрать установщик; ограничения бесплатного тарифа GitHub зависят от типа репозитория и учётной записи.

## Структура

- `src/` — React/TypeScript интерфейс.
- `src-tauri/src/` — Rust-команды и SQLite.
- `src-tauri/tauri.conf.json` — параметры desktop-окна и NSIS-инсталлятора.
- `scripts/build-windows.ps1` — сборка и переименование setup.exe на Windows.
- `.github/workflows/windows-build.yml` — автоматическая сборка Windows artifact.
